# EsseKZ · Ойың — қазына. Сөзің — қанат.

Қазақ тілінде эссе жазуға арналған интеллектуалды веб-қосымша. Дизайн: ашық көк, алтын, ақ; ұлттық ою, қаламұш пен қанатты векторлық медальон. Интерфейс қазақ тілінде және телефонға бейімделген.

## Осы кезеңде не жұмыс істейді?

- Басты бет, жоба туралы, көмек, құпиялық және қолдану шарттары.
- Тіркелу, кіру, HttpOnly cookie сессиясы, профиль есімін өзгерту және шығу.
- 12 эссе түрі, 6 стиль, 5 аудитория, 150–500 сөз, 1–5 дәлел, қарсы пікір мен дереккөз опциялары.
- «Өзім жазамын» режимі: өз мәтініңізді базаға сақтау, өңдеу, жеке тарихтан іздеу, сүзгілеу, өшіру.
- PDF, DOCX, TXT экспорт. Қазақ әріптері сақталады.
- Backend пен деректер базасы нақты жұмыс істейді. Дайын/жалған AI нәтижелері жоқ.

**Пайдаланушының таңдауы бойынша Gemini кілті қазір қосылмаған.** Генерация батырмасы өшірулі, себебі көрсетіледі. Серверлік Gemini модулі келесі кезеңге дайын; кілтсіз API 503 қайтарады және эссе жасамайды. Эссені талдау, балл қою, OCR және жалған пікірлер жоқ.

Құпия сөзді қалпына келтіру беті мен бір рет қолданылатын, 30 минуттық токен логикасы бар. Нақты email жіберу үшін SMTP қажет; қосылмайынша интерфейс шектеуді анық көрсетеді.

## GitHub арқылы жұмыс істеу

Кодты GitHub-та сақтауға және өзгерістерді Pull Request арқылы тексеруге болады. Компьютерге VS Code орнату міндетті емес. `.github/workflows/ci.yml` push/PR кезінде TypeScript, build, backend және browser тесттерін іске қосады.

**GitHub Pages толық қосымшаны іске қоспайды:** сессия, PostgreSQL және Gemini үшін Node.js backend керек. Жариялау үшін GitHub репозиторийін Node.js хостингке (мысалы, Render) байланыстырыңыз. Бұл репозиторийді жазу өздігінен хостинг жасамайды.

Хостинг баптауы:

1. Node.js **22.12 немесе жаңарақ** (ұсыныс: жаңартылған LTS).
2. Build: `npm ci --include=dev && npm run build`.
3. Start: `npm start`.
4. PostgreSQL құрып, оның connection string мәнін **құпия** `DATABASE_URL` айнымалысына орнатыңыз.
5. `NODE_ENV=production`, `APP_ORIGIN=https://сіздің-доменіңіз` орнатыңыз. `APP_ORIGIN` соңында `/` болмасын.
6. Бір сенімді reverse proxy артында болса ғана `TRUST_PROXY_HOPS=1` орнатыңыз. Нақты proxy санына сай таңдаңыз.
7. Health check: `/api/health`.
8. Gemini-ді кейін қосу үшін хостинг құпияларында `GEMINI_API_KEY` орнатыңыз, серверді қайта іске қосыңыз.

Платформа тарифтері мен PostgreSQL сақтау талаптарын хостингте тексеріңіз. Бұл жоба хостинг аккаунтын автоматты ашпайды және ақылы ресурстарды жасамайды.

## Технологиялар және құрылым

React 19 + TypeScript + Vite + Tailwind CSS 4; Express + TypeScript; PostgreSQL (`pg`). Жергілікті әзірлеу үшін PGlite қолданылады — бұл SQLite не mock емес, PostgreSQL-дің WebAssembly қозғалтқышы. Өндірістік орта міндетті түрде сыртқы PostgreSQL-ге қосылады.

```text
src/                    React беттері, компоненттер, стильдер
public/                 SVG логотипі және кітап иллюстрациясы
shared/schema.ts        Параметрлер, Zod валидациясы, сөз санау
server/app.ts           REST API, авторизация, экспорт
server/gemini.ts        Gemini JSON жауабы, retry, сапа тексерісі
server/markers.ts       Қазақ тіліндегі логикалық маркерлер
server/db.ts            PostgreSQL / жергілікті PGlite
server/migrations/      Қайталанғанда қауіпсіз SQL схема
assets/fonts/           Қазақ әріптерін қолдайтын PDF қарпі + лицензия
tests/                  Backend және Chromium browser тесттері
```

## Бұлттық немесе жергілікті іске қосу

```sh
npm ci
cp .env.example .env
npm run dev
```

Frontend порты 5173, backend порты 3001. Vite `/api` сұрауларын backend-ке жібереді. `.env` файлы қажет болмаса да, Gemini кілтінсіз барлық қолмен жазу функциясы жұмыс істейді.

`DATABASE_URL` бос болса, деректер `.local/postgres` ішіне сақталады. Бұл папка Git-ке кірмейді. Оны өшіру жергілікті аккаунттар мен эсселерді жояды. Бір PGlite каталогын екі процесс бір уақытта ашпауы керек.

Сыртқы PostgreSQL қолдану үшін:

```env
DATABASE_URL=postgresql://USER:PASSWORD@HOST:5432/DATABASE
```

Бұл тек үлгі. Нақты құпия мәндерді репозиторийге жазбаңыз. Провайдер талап етсе, TLS connection string параметрлерін оның нұсқаулығына сай қосыңыз; сертификат тексерісін өшірмеңіз. Кестелер сервер іске қосылғанда `server/migrations/001_initial.sql` арқылы жасалады.

Бір порт арқылы жиналған қосымшаны тексеру:

```sh
npm run build
APP_ORIGIN=http://localhost:3001 npm start
```

## Gemini-ді кейін қосу

Google AI Studio-да жасалған кілт тек сервердің `.env` немесе хостинг құпияларына қосылады:

```env
GEMINI_API_KEY=
GEMINI_MODEL=gemini-2.5-flash
```

Кілтті frontend-ке, `VITE_*` айнымалыларына, чатқа, workflow файлына не GitHub репозиторийіне енгізбеңіз. Осы кезеңде нақты Gemini сұрауы әдейі орындалмаған.

Модуль таңдалған параметрлер мен маркерлерді жібереді, JSON-ды Zod арқылы тексереді, сөз санын өзі есептейді, қазақ әріптерін, ±15% көлемін, тыйым салынған бөлім тақырыпшалары мен клишелерді тексереді. Уақытша HTTP қателері/жарамсыз жауаптар үшін ең көбі 4 әрекет жасайды: 5, 10, 15 секунд күту, бірақ бүкіл операцияға 90 секундтан артық берілмейді. Бір сұрау 45 секундпен шектеледі. Таймаут пен желі/TLS қателері автоматты қайталанбайды; олардың қауіпсіз кодтары бөлек көрсетіледі. Сапа тексерісі деректердің ғылыми дұрыстығын немесе дереккөздердің шынайылығын растамайды.

### Gemini қосылмаса

Кілттің бар болуы (`Gemini configured`) Google оны қабылдағанын білдірмейді. Осы папкада орындаңыз:

```powershell
node scripts/check-gemini.mjs
```

Команда `.env` файлын оқиды, кілтті экранға шығармайды және Google-дан қолжетімді модельдер тізімін сұрайды. Эссе генерациясын жібермейді. `GOOGLE_HTTP`, `GOOGLE_STATUS`, `GOOGLE_REASON` қатені анықтауға көмектеседі. `MODEL_AVAILABLE: no` болса, `AVAILABLE_MODELS` тізіміндегі эссе жазуға жарамды модельді `.env` ішіндегі `GEMINI_MODEL` мәніне қойып, серверді қайта іске қосыңыз. Қате кілт/рұқсат/модель сұраулары қайталанбайды; уақытша 429/5xx қателері қайта тексеріледі.

Node.js 22.11 Vite 7 талабына сай емес: жаңартылған LTS нұсқасын орнатыңыз. Бұл ескерту Google API-дан келген HTTP қатесінен бөлек.

Егер тізім ашылып, эссе жазу істемесе, генерацияны бөлек тексеріңіз:

```powershell
node scripts/check-gemini.mjs --generate
```

Бұл команда таңдалған модельге **бір ғана қысқа нақты генерация сұрауын** жібереді (провайдер квотасын қолданады), 45 секундқа дейін күтеді, жауаптың JSON пішінін тексереді. Кілтті, эссе мәтінін және Google-дың шикі қате хабарламасын шығармайды. `GENERATION_HTTP`, `GENERATION_RESULT`, `NETWORK_ERROR`, `ELAPSED_SECONDS` нәтижелерін қолдау үшін бөлісуге болады. `.env` пен деректер базасы өзгермейді. Сертификат тексерісін өшірмеңіз.

## Email арқылы қалпына келтіру

`SMTP_HOST`, `SMTP_PORT`, `SMTP_FROM`, қажет болса `SMTP_USER`, `SMTP_PASS` орнатыңыз. Сервер расталған TLS қосылымын пайдаланады. Email қызметін баптау хат жіберуге рұқсат беруді білдірмейді: нақты провайдерде доменді/жіберушіні растау қажет болуы мүмкін. SMTP кілттері де тек серверде сақталады.

## Экспорт қарпі

PDF: A4, 14 pt, ендірілген **DejaVu Serif** (қазақ таңбалары, лицензиясы `assets/fonts/LICENSE.txt`). Times New Roman коммерциялық қарпі репозиторийге көшірілмейді. Заңды `.ttf` файлыңыз болса, серверде `PDF_FONT_PATH` арқылы таңдаңыз. DOCX құжатында Times New Roman 14 pt көрсетілген; қаріпті оны ашатын құрылғы қамтамасыз етеді.

## API

| Әдіс             | Мекенжай                                                    | Мақсаты                           |
| ---------------- | ----------------------------------------------------------- | --------------------------------- |
| GET              | `/api/health`                                               | База мен қызметтердің күйі        |
| POST             | `/api/auth/register`, `/api/auth/login`, `/api/auth/logout` | Аккаунт және сессия               |
| GET              | `/api/auth/me`                                              | Ағымдағы пайдаланушы              |
| PUT              | `/api/auth/profile`                                         | Есімді жаңарту                    |
| POST             | `/api/auth/forgot-password`, `/api/auth/reset-password`     | Email арқылы қалпына келтіру      |
| POST             | `/api/essays/generate`                                      | Gemini генерациясы (кілт қажет)   |
| POST             | `/api/essays`                                               | Қолмен жазылған мәтінді сақтау    |
| GET              | `/api/essays?search=&type=&offset=0`                        | Жеке тарих (20 нәтиже/бет)        |
| GET, PUT, DELETE | `/api/essays/:id`                                           | Жеке эссені оқу/өңдеу/өшіру       |
| GET              | `/api/essays/:id/export/pdf`                                | PDF (`docx`, `txt` да қолжетімді) |

Барлық эссе endpoint-тері авторизацияны және иелік құқығын тексереді. Құпия сөздер scrypt хэшімен сақталады, сессия токендері базаға хэш түрінде жазылады. Генерация — минутына 10 сұрау; бір серверде қатарынан ең көбі 3 генерация. Таратылған хостингке шыққанда ортақ rate-limit/session тазалау саясатын қосу қажет. Басқа origin-нен mutation сұрауларына тыйым салынады; frontend пен API бір доменде қызмет етеді.

## Тексеру

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Егер Chromium орнатылған болса: `CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e`. Backend тесттері оқшауланған PostgreSQL жады базасын пайдаланады. Browser тесттері `.local/e2e-postgres` базасын қолданады. `TEST_DATABASE_URL` берілсе, backend тесттері сол **арнайы тест** PostgreSQL базасында жұмыс істейді; production URL бермеңіз.

Browser тексерісі: desktop және mobile, тіркелу → мәтін сақтау → редакциялау → PDF/DOCX/TXT жүктеу → тарих іздеу → жою → профиль өзгерту → шығу → қорғалған бет. Gemini қате/JSON/retry логикасы тек тестке арналған provider жауаптарымен тексеріледі; олар қосымшаға қосылмайды. Нақты Gemini мен SMTP қызметтері кілттер қосылған соң бөлек тексеріледі.
